# Smart Organizer

갤럭시 Z 폴드 계열을 고려한 Android 기반 파일 정리·런처·배경화면·데스크톱 커스터마이징 앱입니다. 기기별 실제 동작은 Android 버전과 제조사 기능 지원 여부에 따라 달라질 수 있습니다.

## 구현된 주요 기능

### 파일 및 앱 관리
- 사용자가 SAF 파일 선택기에서 허용한 폴더를 재귀 탐색
- 파일명·상대 경로·크기 확인
- 동일 크기 파일 후보에 대한 SHA-256 중복 판별
- 실행 가능한 설치 앱 목록 조회 및 앱 바로가기 연결
- 파일 작업은 사용자 선택과 Android 권한 범위 내에서 수행

### 런처 및 Fold 화면 대응
- 커버·북·테이블탑·내부 화면 상태 감지 기반 레이아웃 분리
- 앱 아이콘 배치 및 커스텀 런처 화면
- Fold 자세별 레이아웃 저장
- 기기에서 제공하는 WindowManager 폴딩 정보 활용

### 배경화면 및 테마 제작 도구
- 사진·동영상·GIF 배경화면 관련 스튜디오
- 이미지 기반 배경화면 편집 흐름
- 스타 테마/캐릭터 테마용 설정 허브 및 아이콘 미리보기
- Cyber Formula 스타일 대시보드와 홈 화면 위젯
- 충전 연결 알림에서 저장한 영상 미리보기 실행
- 매일 배경화면 예약 적용 및 기기 재부팅 후 예약 알람 복구
- Good Lock / QuickStar / Theme Park / Wonderland 앱 실행 또는 Galaxy Store 설치 페이지 연결

### Desktop Studio
- 앱 내부에서 동작하는 데스크톱 스타일 캔버스와 작업 표시줄
- 시계·날짜·배터리·메모·앱 바로가기 위젯
- 위젯 이동, 크기 변경, 텍스트 수정, 삭제
- Fold 자세별 배치 및 저장
- Windows 스타일 / Cyber Formula HUD / 미니멀 시계 프리셋
- `.sod.json` 레이아웃 내보내기 및 가져오기
- Android AppWidgetHost 기반 설치 앱의 실제 위젯 추가·구성·삭제 (앱 내부 위젯 보관 화면)
- ML Kit 객체 감지를 이용한 이미지 객체 태그 오버레이 생성 및 편집

## 중요한 범위와 제한

- Desktop Studio는 앱 안에서 동작하는 데스크톱 스타일 편집 화면이며 Android 시스템 전체를 Windows 데스크톱으로 대체하지 않습니다.
- ML Kit 기능은 이미지 내 객체 감지와 라벨 오버레이입니다. 임의의 UI를 완전히 이해하거나 이미지 디자인을 실제 동작하는 위젯으로 100% 재구성하는 기능은 아닙니다.
- 객체 감지 결과는 이미지 크기·화면 비율·배경 크롭 방식에 따라 위치 오차가 생길 수 있습니다.
- Android 위젯 호스트는 Smart Organizer 내부에 실제 AppWidgetProvider를 표시합니다. 삼성 One UI 홈 화면에 위젯을 직접 배치하거나 KWGT와 동일한 자유 편집을 제공하는 것은 아닙니다.
- Quick Panel 및 Good Lock의 삼성 전용 UI를 외부 앱에서 직접 교체하거나 제어하는 것은 공개 Android API만으로 보장되지 않습니다. 관련 도구는 아이콘 제작과 설치된 모듈 실행/스토어 연결을 제공합니다.
- 독립적인 커버/내부 화면 배경화면 적용, 제조사 전용 테마 포맷, 시스템 아이콘 전체 교체는 One UI 버전과 삼성 API/권한에 종속됩니다.
- 폴딩 상태 감지와 UI는 실제 Fold 기기에서 별도 검증이 필요합니다. CI 빌드 성공은 실기기 호환성 검증을 의미하지 않습니다.
- 저장소의 기능은 단계적으로 확장 중이며, 각 화면과 기기 조합에 대한 완전한 동등 기능을 보장하지 않습니다.

## 빌드 환경

- Android / Kotlin
- JDK 17
- Android SDK 35
- minSdk 26
- AndroidX WindowManager
- Google ML Kit Object Detection

Android Studio에서 저장소를 열고 Gradle Sync 후 앱 모듈을 빌드합니다. GitHub Actions에서 수행한 빌드 결과는 Actions 탭에서 확인할 수 있습니다.

## 개발 원칙

- 실제 파일·앱 데이터와 플랫폼이 제공하는 정보에 기반
- 사용자 승인 없이 파일을 자동 삭제하지 않음
- 분석 결과와 기능의 한계를 명확히 표시
- CI 컴파일 결과와 실기기 검증 결과를 구분
- 제조사 비공개 API나 권한을 공개 API처럼 가장하지 않음
