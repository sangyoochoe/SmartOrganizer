# Smart Organizer · v0.2.0

갤럭시 Z 폴드7을 우선 대상으로 하는 Android 앱의 첫 개발 단계입니다.

## 이번 버전에서 구현한 것
- Android Storage Access Framework로 사용자가 직접 선택한 폴더에 접근
- 선택 폴더의 하위 폴더까지 재귀 탐색
- 실제 파일명, 상대 경로, 크기 표시
- 동일 크기 파일만 후보로 추린 뒤 SHA-256으로 내용이 완전히 같은 파일 그룹 확인
- Android가 공개하는 실행 가능한 설치 앱 목록 조회
- 가짜 파일/샘플 결과 미사용
- 파일 이동/삭제 미구현 (현재 버전은 읽기 전용 분석)

## 현재 한계
- 앱은 임의로 전체 저장공간을 스캔하지 않습니다. 사용자가 파일 선택기에서 허용한 폴더만 검사합니다.
- Android/data 등 시스템이 제한한 위치는 접근되지 않을 수 있습니다.
- 앱 목록은 실행 가능한 앱 중심이며 모든 패키지/시스템 앱 목록을 의미하지 않습니다.
- 이 버전은 악성코드 백신이 아닙니다. SHA-256은 중복 판별용이며 악성 여부를 판단하지 않습니다.
- 유사 파일, APK 권한/서명/매니페스트 정밀 분석, 규칙 기반 분류, 삭제/이동, 커스텀 런처는 후속 단계입니다.


## 다음 단계용 코드 기반 추가 (아직 기능 구현 전)
이번 커밋에는 후속 기능을 실제 구현할 때 공통으로 사용할 Kotlin 모델을 추가했습니다.
- `core/model/FileRecord.kt`: SAF에서 읽은 실제 파일/폴더의 공통 표현
- `core/model/AnalysisFinding.kt`: 근거·심각도·관련 경로를 갖는 분석 결과
- `features/organization/OrganizationRule.kt`: 사용자 규칙 및 승인 대기 분류 제안
- `features/operations/FileOperationRecord.kt`: 이동/이름 변경/휴지통 작업 이력
- `features/security/SecurityAssessment.kt`: 오탐 가능성과 분석 한계를 포함하는 보안 평가
- `features/apps/InstalledAppCategory.kt`: 설치 앱 분류 제안
- `features/launcher/LauncherLayoutDraft.kt`: 접힘/펼침 런처 배치 초안

**중요:** 위 항목은 후속 구현을 위한 데이터 모델이며, 해당 기능의 화면·분석 엔진·파일 변경 동작이 이미 완성됐다는 뜻은 아닙니다. 현재 동작하는 기능은 위의 v0.2.0 구현 범위와 동일합니다. 기능을 추가할 때마다 빌드와 실제 기기 검증을 별도로 진행합니다.

## 구현 로드맵
1. 다운로드 폴더 분석: 대용량/오래된 파일/동일 이름/동일 내용/유사 후보
2. APK 메타데이터·권한·서명 분석 및 근거 기반 위험 표시
3. 사용자 확인을 거치는 파일 이동·이름 변경·삭제/복원과 작업 이력
4. AI 추천 + 사용자 규칙 기반 폴더 분류
5. 설치 앱 분류 및 관리
6. 사진 기반 커스텀 런처: 설치 앱 연결, 사용자가 배치 수정, Fold7 접힘/펼침 레이아웃

자동 삭제는 구현하지 않으며, 보안 평가는 악성 여부를 단정하지 않습니다. 런처는 파일 관리 기능이 안정화된 뒤 마지막에 구현합니다.

## 빌드
1. Android Studio에서 이 폴더를 엽니다.
2. JDK 17 및 Android SDK 35를 설치합니다.
3. Gradle Sync를 실행합니다.
4. Run 또는 Build > Build APK(s)를 선택합니다.

환경에 따라 Gradle 플러그인/SDK 다운로드가 필요합니다. 이 환경에서는 Android SDK 빌드를 실행하지 않았으므로 APK 컴파일 성공을 보증하지 않습니다.

## 개발 원칙
- 실제 기기 데이터만 표시
- 읽을 수 없는 파일은 검사에서 제외하고 임의 결과를 만들지 않음
- 자동 삭제하지 않음
- 보안 결과는 근거와 신뢰도를 함께 표시하고, 정상 개발 코드의 오탐 가능성을 명시
- 홈 화면 사진 분석/커스텀 런처는 파일 관리 기능 안정화 후 마지막 단계에서 구현
